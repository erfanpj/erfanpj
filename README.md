## Brain Signals Lab

I kept each participant's recordings in a single fold. Across 50 people and five folds, CSP + LDA averaged **61.8%** accuracy. A most-frequent-class baseline reached **50.4%**. Open **Participants** in the [viewer](https://erfanpj.github.io/brain-signals-lab/viewer/) to see how widely results varied. Saved JSON reports load in the browser without retraining. These are engineering results on one public dataset, not clinical or neuroscience claims.

## OpsDesk AI

Changing an approved ticket proposal invalidates its approval. A second execution request returns the first receipt. I compared a rules baseline with a local language model on 60 fictional tickets: the rules produced **37** fully correct proposals and the model produced **25**. The [browser fixture](https://erfanpj.github.io/opsdesk-ai/) simulates approve-and-receipt flows; the Python desk runs on your machine only. [Repository](https://github.com/erfanpj/opsdesk-ai)

I used AI coding assistants while building these projects; each README states what's fictional and what requires a local run.
